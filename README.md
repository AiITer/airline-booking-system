# Airline Booking Backend

A Java Spring Boot airline booking backend project focused on system architecture, concurrency, distributed systems, and reliable transactions.

## Planned scope

- Flight search and availability
- Seat reservation and booking
- Simulated payment flow
- Cancellation and seat release
- PostgreSQL transactions
- Concurrency control
- Redis caching
- Messaging and asynchronous workflows
- Docker and observability
- Load testing and distributed-system evolution

## Tech Stack

- Java 25 LTS
- Spring Boot
- Maven
- PostgreSQL
