# Development Roadmap

## Phase 1 — Core Backend

- Spring Boot project structure
- Flight search
- Seat availability
- Booking creation
- Simulated payment
- Cancellation and seat release
- PostgreSQL persistence

## Phase 2 — Correctness and Concurrency

- Database transactions
- Concurrent seat reservation
- Locking strategies
- Transaction isolation
- Idempotency
- Indexing and query performance

## Phase 3 — Performance and Asynchronous Processing

- Redis caching
- Message queue
- Background processing
- Retry and failure handling
- Load testing

## Phase 4 — Distributed Evolution

- Split services only where justified
- Service-to-service communication
- Saga and compensation
- Multi-instance deployment
- Fault recovery

## Phase 5 — Production Engineering

- Docker
- Automated tests
- Logging and metrics
- Prometheus and Grafana
- CI/CD
- Lightweight cloud deployment
